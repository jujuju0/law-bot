# Before / After 데모 3개

모두 `eval/results/`에 저장된 dev 평가 결과(검색)에서 가져온 실제 출력이다. 재현: `uv run python -m eval.evaluate --config <config>` 후 질문 ID로 확인.

## 1. 구조 청킹 — q009 "인공지능기본법 31조를 요약해 주세요." (E0 → E1)
| | 상위 5개 | 정답 `법 제31조` |
|---|---|---|
| Before (E0, 고정 500자) | 법 제40조~제41조 / 법 제3조~제6조 / 법 제1조~제2조 / 법 제6조 / 법 제36조~제38조 | 없음 |
| After (E1, 조·항 구조 청킹) | **법 제31조** / 법 제22조의2 제9항 / 법 제5조 / 법 제40조 / 법 제3조 | **1위** |

고정 길이 청크는 여러 조를 이어 붙여 조 경계를 깨고, 구조 청킹은 조 번호·제목이 청크 안에 남는다.

## 2. Hybrid (BM25 + RRF) — q013 "AI로 그림을 만들어 주는데 결과 이미지에 뭘 표시해야 하나요? 워터마크로 해도 되나요?" (E2 → E3)
| | 상위 5개 | 정답 `법 제31조` |
|---|---|---|
| Before (E2, dense) | 법 제2조 제5호 / 법 제26조 제6항 / 법 제16조 제5항 / 법 제26조 제2항 / 법 제26조 제4항 | 없음 |
| After (E3, + BM25) | 법 제2조 제5호 / **법 제31조** / 법 제32조 / 법 제26조 제6항 / 법 제16조 제5항 | **2위** |

용어("표시", "생성")가 정확히 겹치는 조문을 BM25가 끌어온다. 단, E3 전체 Hit@1은 오히려 내려갔고(0.552→0.483) 후보 재현율이 올랐다(Cand-R@20 +0.086). 순위는 다음 단계 Rerank가 바로잡는다(E4 Hit@1 0.759).

## 3. Delegation expansion — q014 "해외 AI 회사라 한국에 사무실이 없어요. 한국에서 서비스하려면 따로 해야 하는 게 있나요?" (E8 → E9)
| | 컨텍스트에 포함된 정답 (`법 제36조`, `영 제29조`) |
|---|---|
| Before (E8) | 법 제36조만. 시행령 제29조(국내대리인 지정 기준)가 빠짐 |
| After (E9) | 법 제36조 + **영 제29조** (`added_by=delegation`, `via=law:a36`) |

법 제36조가 "대통령령으로 정한다"로 위임한 조문을 위임 그래프로 따라가 시행령을 컨텍스트에 붙인다. q017도 같은 방식으로 영 제2조 → 법 제4조를 회수했다. dev 전체 Full-Recall@ctx는 0.714 → 0.809이고, 결과 개수만 늘린 대조군(E8_sources_k8)은 0.714로 변화가 없다.
> 한계: test split(12문항)에서는 E8과 E9의 Full-R@ctx가 같았다(둘 다 0.625). dev 2문항 개선이 test에서는 재현되지 않았다.
