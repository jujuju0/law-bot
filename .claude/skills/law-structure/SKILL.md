# 법령 구조·청킹 레퍼런스

구조(장/조/항/호/목)는 Open API 응답 계층에서 가져온다(`/law-api` 참고). 정규식은 **본문 안의 참조·위임 탐지**와 **행정규칙 조 분할**에만 쓴다.

## 계층
```
제N장 > 제N절(법률 제3장에만) > 제N조(제목) > ①항 > 1.호 > 가.목
```
- 가지번호 조: 제22조의2 (`조문가지번호=2`)
- 개정 표시: `<개정 2026. 1. 20.>`, `<신설 ...>`, `[제목개정 ...]` → `amended` 메타로 추출 후 embed_text에서는 제거
- 시행일 주석: `[시행일: 2026. 1. 24.] ...` → 해당 조 메타

## 정규식 (Python)
```python
AMEND      = re.compile(r"<(개정|신설)\s*(\d{4})\.\s*(\d{1,2})\.\s*(\d{1,2})\.>")
DELEGATE   = re.compile(r"대통령령으로\s*정(한다|하는)|고시(하여야|하고|한다)|부령으로\s*정")
# 같은 법 내 참조 (「다른법」 참조는 먼저 마스킹)
OTHER_LAW  = re.compile(r"「[^」]+」\s*(제\d+조(의\d+)?(제\d+항)?(제\d+호)?)?")
INTERNAL   = re.compile(r"제(\d+)조(?:의(\d+))?(?:제(\d+)항)?")
# 시행령 → 법률 위임 근거
FROM_LAW   = re.compile(r"법\s*제(\d+)조(?:의(\d+))?(?:제(\d+)항)?(?:제(\d+)호)?에\s*따(라|른)")
ANNEX_REF  = re.compile(r"별표\s*(\d+)(?:의(\d+))?")
# 행정규칙 조문 분할 (조문내용이 문자열 리스트로 올 때)
ADMRUL_ART = re.compile(r"^\s*제(\d+)조(?:의(\d+))?\(([^)]+)\)", re.M)
PARA_SYM   = "①②③④⑤⑥⑦⑧⑨⑩⑪⑫⑬⑭⑮⑯⑰⑱⑲⑳"
```
주의
- `INTERNAL` 적용 전 `OTHER_LAW`로 「다른 법률」 부분을 공백 치환 (예: 「에너지법」 제2조제1호 → refs에 들어가면 안 됨)
- 시행령 본문의 `제N조`(접두 "법" 없음)는 **시행령 자신의** 조문 참조
- 자기 자신 조는 refs에서 제외

## chunk_id 규칙 `{source_type}:{local}`
| 대상 | local | 예 |
|---|---|---|
| 조 | `a{조}` / 가지 `a{조}_{가지}` | `law:a31`, `law:a22_2` |
| 항 | `a{조}-p{항}` | `law:a31-p2` |
| 법 제2조 호 | `a2-i{호}` | `law:a2-i4` |
| 부칙 | `add{순번}` | `law:add1` |
| 별표 행그룹 | `{별표번호}-r{그룹}` / 비고 `{별표번호}-note` | `annex:1-r3` |
| 행정규칙 조 | `{ID}-a{조}` | `admrul:2100000xxxxx-a3` |
| 용어 | 용어명 | `term:고영향 인공지능` |
| 해석례 | `{ID}` / 이유 `{ID}-reason` | `expc:123456` |
| naive | `naive-{순번}` | `law:naive-007` |

## citation 규칙 (답변·sources 공통)
| 원천 | 형식 |
|---|---|
| 법률 | `법 제31조 제2항`, `법 제2조 제4호`, `법 부칙 제1조` |
| 시행령 | `영 제22조 제1항` |
| 별표 | `영 별표 1` (행그룹은 citation 동일) |
| 행정규칙 | `고시 {행정규칙명 축약} 제3조` |
| 용어 | `법령용어 {용어}` |
| 해석례 | `법령해석례 {해석기관} {해석일자}` |
답변 안에서는 `[ ]`로 감싼다. 후처리는 `\[([^\]]+)\]`로 추출해 citation 집합과 대조.

## embed_text
```
[{법률|시행령|고시|별표|용어|해석례} > {chapter}{ > section}] {article}({article_title}) {paragraph} {text}
```

## 테스트 기대값 (법률, 2026-01-22 시행본 기준)
- 본문 조 수: 44 (제1조~제43조 + 제22조의2), 장 6개
- 제2조 호 12개, 4호의 목 11개(가~카), 7호의 목 2개
- 제31조 항 4개, 제43조 항 2개
- 제43조 ① 각 호가 참조하는 조: 31, 36, 40 → `law:a43` refs ⊇ {31, 36, 40}
- `delegated=true`여야 하는 예: 제31조④, 제33조④, 제35조③, 제36조①
- 시행령은 수집 후 실제 조 수를 확인해 기대값 추가
