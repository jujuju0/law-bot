### E3 — + BM25 + RRF (2026-10-08)
- **가설:** 법률 용어 정확 일치(국내대리인, 과태료, 영향평가)를 dense가 놓치는 경우를 BM25가 보완한다.

- **결과 파일:** `eval/results/20261008-135011_E3_hybrid.json`
- **수치(E2 대비):** Hit@1 0.552→0.483 (−2문항) / Hit@3 0.655→0.621 (−1) / Hit@5 0.655→0.690 (+1) / Full-R@5 0.095→0.143 / **Cand-R@20 0.517→0.603 (+0.086)**, 후보 Hit@20 0.759→0.862 (+3문항)
- **참고:** BM25 단독 Hit@1 0.586·MRR 0.622 (dense 0.552·0.586보다 높음). `rrf_k` 민감도 1/5/10/20/60 → Hit@1 0.55/0.48/0.48/0.48/0.48, Hit@3 0.69/0.69/0.66/0.66/0.62 — 차이 1~2문항으로 노이즈 범위라 표준값 60 유지(dev 과적합 회피).
- **개선:** q013(AI 그림 표시 → 법 제31조 2위), q038·q040 / **악화:** q005(정의 → 3위), q009("31조 요약" → 4위, BM25가 `31` 토큰으로 다른 조의 "제31조" 언급을 끌어옴), q014
- **해석:** 상위 순위 정밀도는 RRF로 dense·BM25 의견이 갈릴 때 평준화돼 약간 떨어지지만, **정답 후보를 20개 안으로 끌어오는 재현율은 확실히 오른다.** 순위 정밀도는 다음 단계(Rerank)가 담당하는 구조이므로 1단계 후보 생성기로 채택. 조문번호 질문의 숫자 매칭 노이즈는 Router(E5)로 해결.
